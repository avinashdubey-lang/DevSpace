# DevSpace

**A developer-focused workspace to organize tasks, manage projects, and stay focused.**

DevSpace is a productivity platform designed around the way developers work. It brings task organization, project tracking, and focused work sessions into one workspace.

The goal is to make it easier to plan work, track progress, and maintain focus without unnecessary complexity.

## Features

- **Kanban Board** — Organize tasks across Backlog, Todo, In Progress, In Review, and Done.
- **Task Management** — Track task IDs, priorities, labels, assignees, and due dates.
- **Dashboard** — Get a quick overview of your workspace and active work.
- **Focus Mode** — A dedicated space for focused work sessions.
- **Developer-Oriented UI** — A dark, minimal interface inspired by modern developer tools.

*Note: DevSpace is currently under active development. Features are being implemented incrementally.*

## Tech Stack

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/avinashdubey-lang/DevSpace.git
   ```

2. Open the project folder in your code editor.

3. Open `index.html` in a browser. For ES module support, running the project through a local development server is recommended.

## Current Development

The project is being built incrementally, starting with a modular JavaScript architecture and state-driven UI rendering. Planned improvements include task creation and editing, Kanban interactions, search and filtering, local persistence, and enhanced Focus Mode functionality.

## Motivation

DevSpace is both a practical productivity tool and a project for developing stronger frontend engineering skills through building, testing, and refining a real application.
